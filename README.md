# 🏕️ Wild Oasis - Booking Dashboard SPA

Welcome to **Wild Oasis**, a modern single-page hotel/retreat booking dashboard built with **React**, **React Router**, and **React Query**. This project demonstrates routing, protected layouts, API data fetching, dark mode context, and a production-ready UI flow.

🔗 **Live Site:** [adarsh-wild-oasis.netlify.app](https://adarsh-wild-oasis.netlify.app/)

---

## 🚀 Features

- 🔐 **Protected Routes** with login flow using `<ProtectedRoute />`
- 🗺️ **Client-side Routing** using `react-router-dom`
- 🧠 **Caching & Fetching** with `@tanstack/react-query`
- 🌓 **Dark Mode Support** using Context API
- ✅ **User & Admin Dashboard Views**
- 📦 Modular page structure for Cabins, Users, Settings, and Bookings
- 🔥 Toast Notifications via `react-hot-toast`
- 🛠️ React Query DevTools for development debugging

---

| Tech                | Purpose                         |
